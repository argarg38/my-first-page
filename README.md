# 바이브코딩 4주 처방전

약토피아 대학생 서포터즈 **바이브코딩 기초 트랙(2026.09.07 — 10.04)** 4주간의 활동 기록 페이지입니다.

약국이라는 주제를 살려 4주 과정을 "주 1회 · 총 4회 복용하는 처방"에 빗대었고,
화면은 iOS 설정·건강 앱의 그룹형 리스트 스타일로 만들었습니다.

## 구성

| 영역 | 내용 |
|---|---|
| 처방 정보 | 수강생 · 트랙 · 기간 · 용법 |
| 진행 상황 | 4주 중 몇 주가 끝났는지 |
| 주차별 기록 | 주차마다 `효능(배운 것) / 조제(만든 것) / 부작용(막힌 것)` |
| 쓰고 있는 도구 | 이미 써 본 것(실선) / 앞으로 만날 것(점선) |
| 4주 뒤 목표 | 트랙을 마칠 때 남기고 싶은 것 |

## 보는 방법

`index.html` 파일을 브라우저로 열면 됩니다. 별도 설치나 빌드 과정이 없습니다.

## 내용 고치는 방법

`index.html` 아래쪽 `<script>` 안의 다음 구역만 고치면 화면이 바뀝니다.

```
▼▼▼ 여기만 고치면 페이지 내용이 바뀝니다 ▼▼▼
```

- `내정보` — 이름, 소속, 기간
- `주차기록` — 주차별 내용. `상태`를 `"upcoming"`(예정) → `"active"`(진행 중) → `"done"`(완료)로 바꾸면
  진행 바와 "N/4회 복용" 표시가 자동으로 따라옵니다.
- `도구목록`, `목표`

## 만든 것

- HTML · CSS · JavaScript (라이브러리 없이 파일 하나)
- 글꼴: 맑은 고딕 (macOS·iOS에서는 Apple SD 산돌고딕으로 대체)
- 밝은 테마 / 어두운 테마 모두 지원
